# Datos Semilla de Prueba (Seed Data)

En esta carpeta se gestionarán los scripts e instrucciones para poblar la base de datos de desarrollo con datos de prueba controlados a partir de la **Fase 1**:

- Catálogo de productos y categorías ficticios.
- Proveedores de ejemplo.
- Tasas de impuestos de prueba (ej. 16% ilustrativo).
- Usuarios iniciales de prueba (ej. roles `ADMIN` y `CASHIER`).

> **Regla de Seguridad:** Ningún dato sensible, contraseña de producción ni cliente real debe almacenarse en esta carpeta.
